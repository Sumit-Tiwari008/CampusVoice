# CampusVoice 🎓

**Smart Campus Issue Management System**

CampusVoice is a web platform that lets students report campus problems, support issues raised by others, and helps college administration prioritize and resolve them based on real student impact.

## 🚀 Problem It Solves

Instead of students individually complaining about the same broken Wi-Fi, faulty AC, or bad mess food through informal channels, CampusVoice gives everyone one shared place to raise and back issues — so admin can see exactly what's affecting the most students and act accordingly.

## ✨ Features

- **Student Portal**
  - Sign up / Log in
  - Report a new issue with category, location, and description
  - Browse existing issues by category (Hostel, Wi-Fi, Mess, Academics, etc.)
  - Support an existing issue ("I Am Affected") instead of creating duplicates

- **Admin Dashboard**
  - Overview stats: Total, Pending/In Progress, and Resolved issues
  - Manage and update the status of reported issues

- **UI/UX**
  - Clean, modern glassmorphism-style design
  - Dark mode support
  - Fully responsive layout

## 🛠️ Tech Stack

- **HTML5** — page structure
- **CSS3** — custom theme system with CSS variables, dark mode, glow effects, responsive design
- **JavaScript (Vanilla)** — dashboard logic, filtering, dark mode toggle, form handling
